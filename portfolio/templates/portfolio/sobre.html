1. Arquitetura MVT do Django

O que é?

O Django segue o padrão MVT (Model-View-Template), onde cada componente tem uma função específica.

Componentes

  • Model → Dados e base de dados
  • View → Lógica da aplicação
  • Template → Interface (HTML)

Fluxo

  1. URL é chamada
  2. View processa pedido
  3. Model fornece dados
  4. Template apresenta resultado

Diagrama Entidade-Relacionamento

Models.py

class Projeto(models.Model):
    titulo = models.CharField(max_length=200)
    descricao = models.TextField()

class Competencia(models.Model):
    nome = models.CharField(max_length=100)
    nivel = models.IntegerField()
    projetos = models.ManyToManyField(Projeto)
